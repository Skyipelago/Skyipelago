# Skyipelago

Skyipelago is a custom Minecraft 1.21.1 NeoForge world. Completing a mapped FTB Quests quest sends an Archipelago check.

This slice ships nine locations across Spawn and a gated Workshop chapter. Completing Victory is the goal. Workshop checks are locked until Workshop Key is received.

Unmapped flavor quests (for example "Read the Lore") are not checks.
